# Enterprise Active Directory Home Lab

A hands-on Windows Server 2022 enterprise infrastructure project designed to develop practical Systems Administration skills through the deployment, configuration, and management of a complete Active Directory environment.

This repository documents each phase of building an enterprise Windows domain from the ground up using Oracle VirtualBox. Every section includes technical documentation, implementation procedures, screenshots, troubleshooting notes, and explanations of the underlying concepts to demonstrate not only how the environment was built, but why each configuration is important in a production enterprise network.

---

## Project Objectives

- Build an enterprise Windows Server environment from scratch.
- Gain hands-on experience administering Active Directory Domain Services (AD DS).
- Configure core Windows networking services including DNS and DHCP.
- Deploy and manage Windows domain-joined client systems.
- Implement enterprise administration using Organizational Units (OUs), Group Policy Objects (GPOs), and PowerShell automation.
- Strengthen Windows Server troubleshooting methodologies through practical implementation.
- Develop professional technical documentation suitable for portfolio presentation.
